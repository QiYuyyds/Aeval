## MODIFIED Requirements

### Requirement: run 记录其证据采集边界

每个 run MUST 持久化本次评测的证据采集边界信息：是否开启工具入参采集、所依据的规范与映射版本、所用脱敏处理的标识，以及本次评测所使用的**环境身份**（环境的标识与其版本/初始态声明；无环境参与时显式记为无环境）。缺少该记录时 MUST NOT 允许把该 run 与记录了该信息的 run 直接比较。

#### Scenario: 复核一个历史结论

- **WHEN** 有人要判断某个历史 run 为什么缺少参数正确性指标
- **THEN** run 记录可直接回答当时未开启入参采集，无需查配置或猜版本

#### Scenario: 同一结论是否出自同一个环境

- **WHEN** 两次 run 用同一套件跑同一被评 agent，但一次指向新的环境初始态声明
- **THEN** 两者的环境身份不同，比较结论 MUST 报告不可直接比较并给出原因，而不是把差异归给 agent

#### Scenario: 无环境参与时如实记录

- **WHEN** 一次 run 全程没有环境管理参与
- **THEN** 证据边界显式记录「无环境」，历史 run 在本字段缺失时读回为空且不报错

#### Scenario: 环境身份经序列化后端读回后仍能挡住误比

- **WHEN** 两个环境身份不同的 run 先落进序列化持久化的后端、再被读出进行比较
- **THEN** 比较仍报告不可直接比较并给出环境身份差异的原因，读回过程不把它降级成「未记录」
- **AND** 而变更前落盘、当时未记录该字段的 run 在两个存储后端上读回一致的「未记录」语义（既不报错也不冒充无环境）
