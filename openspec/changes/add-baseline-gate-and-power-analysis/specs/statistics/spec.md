# statistics 变更（delta）

## ADDED Requirements

### Requirement: 功效分析输出所需样本量并声明其假设

系统 SHALL 提供样本量规划：给定目标分辨率（通过率区间半宽 δ，或两版本分数差异 d）与基线（假设的通过率 p，或某已落盘 run 的实测 p 与分数标准差），输出达到该分辨率所需的有效 trial 数 N。输出 MUST 同时给出所用的公式假设（通过率为 Wilson 区间宽度反解；连续分数为正态近似）与小样本下近似偏乐观的局限声明——功效分析自己不撒"这数字是精确的"的谎。

#### Scenario: 通过率按目标分辨率反解

- **WHEN** 用户要求在基线通过率 p≈0.7 下以 ±3% 的区间半宽分辨通过率
- **THEN** 输出的 N 使 Wilson 95% 区间半宽 ≤ 0.03，并标注所用公式与置信水平

#### Scenario: 分数差异用正态近似并声明局限

- **WHEN** 用户按某 run 的实测分数标准差询问"分辨差异 d 需要多少 trials"
- **THEN** 输出按正态近似计算的 N，并随附"近似在小样本/偏态分布下偏乐观"的局限说明

#### Scenario: 从已落盘 run 取实测基线

- **WHEN** 指定 `--from-run` 且该 run 含有效 trial 的分数轴
- **THEN** 以该 run 的实测 p 与 σ 为基线计算；无有效样本时报告证据不足而不是以 0 或 1 代算

### Requirement: 基线比较的显著变差以区间不重叠且方向向下为准

两个 run 的"显著变差"判定 SHALL 复用 compare 的可比性前置（统计口径一致且证据边界一致，含环境身份），在可比前提下以套件实测 `pass@1` 的 95% 置信区间为准：区间不重叠 **且** 新值更低才构成显著变差；区间重叠或新值更高均不构成。逐 task 的升降 SHALL 作为诊断量呈现，不参与判定。不可比时 MUST 拒绝给出变差/未变差的任何结论并给 `not_comparable_reason`，而不是硬比。

#### Scenario: 区间不重叠且新值更低

- **WHEN** 基线 run 的 `pass@1` 区间为 [0.62, 0.85]，新 run 为 [0.30, 0.55]
- **THEN** 判定为显著变差

#### Scenario: 区间重叠时拒绝判变差

- **WHEN** 两个 run 的区间有重叠（如 [0.34, 1.0] 对 [0.10, 0.90]）
- **THEN** 不构成显著变差——"不显著"不被读成"没有变化"，输出如实呈现两区间

#### Scenario: 不可比时拒绝判定而非硬比

- **WHEN** 两 run 的统计口径或证据边界（含环境身份）不同
- **THEN** 不给出任何方向性结论，报告 `not_comparable_reason` 并点名差异维度
