## ADDED Requirements

### Requirement: 能力清单声明交互模型可用性

独立部署形态的能力清单 MUST 声明本次运行是否具备多轮会话所需的用户模拟与运行中事件注入能力，使客户端在调用前就能判断该部署能不能跑会话型套件，而不是提交任务后等到一个 `invalid`。清单缺失该声明时，客户端 MUST 能把它当作「不具备」而不是「具备」来处理。

#### Scenario: 客户端先问再提交

- **WHEN** 一个客户端准备提交多轮套件，先读能力清单
- **THEN** 清单如实回答该部署是否支持用户模拟与事件注入
- **AND** 不支持时客户端可以在提交前就给出提示，而不是等 run 产出无效结论
