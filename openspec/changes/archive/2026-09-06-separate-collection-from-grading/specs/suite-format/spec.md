## ADDED Requirements

### Requirement: 敏感证据采集共用一套声明

模型输入输出正文与工具调用入参/结果这两类敏感证据 MUST 通过同一套声明机制控制：默认不采集、可按套件或任务显式开启、开启后强制经过默认启用的脱敏处理、且所用处理的标识随结果落盘。系统 MUST NOT 为不同类别的敏感证据定义互不相干的第二套开关语义。

#### Scenario: 只开一类

- **WHEN** 套件只开启正文采集、未开启工具入参采集
- **THEN** 只有前者被采集与脱敏落盘，后者一律按证据不可用处理，两者在结果记录里各自标明状态

#### Scenario: 组合状态可复核

- **WHEN** 事后要确认某次 run 当时采了什么
- **THEN** 结果记录可直接回答各类敏感证据当时的采集开关与脱敏处理标识，无需查配置或猜测

#### Scenario: 未声明即关闭

- **WHEN** 套件不含任何采集声明
- **THEN** 所有敏感证据均不采集，依赖它们的评分结论报证据不可用而不是判失败
