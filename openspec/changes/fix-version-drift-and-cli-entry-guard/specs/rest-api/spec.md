## ADDED Requirements

### Requirement: 同一进程对外声明的版本必须同源

一个进程对外声明自身版本的**所有**出口（接口文档里的版本字段、能力清单里的版本、版本响应头）MUST 出自同一个解析器，MUST NOT 存在第二处硬编码的版本字面量。两种部署形态（由宿主挂载、以及固定前缀的独立部署）MUST 报出同一个版本号 —— 部署形态可以改变路径前缀与能力清单内容，MUST NOT 改变版本声明。版本解析器本身已存在时，绕过它另写一份字面量属于缺陷，无论该字面量当时是否恰好正确。

#### Scenario: 升级包版本后所有出口同步

- **WHEN** 发行包版本号被提升而没有任何接口层代码改动
- **THEN** 接口文档版本、能力清单版本与版本响应头三处同时反映新版本，无一处仍报旧值

#### Scenario: 两种部署形态给出同一版本

- **WHEN** 同一份已安装的包分别以宿主挂载形态与独立部署形态起服务，并各读一次接口文档
- **THEN** 两处版本字段相同且都等于该包的实际版本 —— 挂载形态不得成为例外

#### Scenario: 出现第二处版本字面量时测试失败

- **WHEN** 有人在接口层新增一处写死的版本字符串
- **THEN** 有一条测试能在 CI 上失败并报出该位置，而不是等到发布后人工比对才发现两处不一致
